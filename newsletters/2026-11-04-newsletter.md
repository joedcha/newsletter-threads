🔹 NOTICIA #1: Claude lanzó Message Threads API en beta pública el 2 de noviembre

La API de Message Threads de Anthropic entró en beta pública el 2 de noviembre. El parámetro "thread" en el API guarda la conversación en los servidores de Claude. Cada llamada siguiente solo envía los mensajes nuevos, no el historial completo. Aplica para Claude Fable 5.1, Opus 4.6, Sonnet 4.6 y más.

Por qué importa:
→ Si tienes una automatización que hace 50 llamadas a Claude en una sesión larga, antes enviabas el historial completo en cada llamada. Ahora solo envías lo nuevo. Eso puede reducir tus costos de API entre 40% y 70% en workflows conversacionales largos.

Cómo aprovechar AHORA MISMO:
→ Si usas la API de Claude directamente, agrega el parámetro "thread" a tus requests y el header "anthropic-beta: message-threads-2026-08-12". Claude guarda el contexto, tú envías menos tokens. Revisa la documentación en platform.claude.com para los modelos compatibles.

Fuente: [Claude Platform Docs - Message Threads](https://platform.claude.com/docs/en/build-with-claude/message-threads.md)

🧠 TUTORIAL CLAUDE DEL DÍA - PASO A PASO

TÍTULO: Cómo usar la nueva Message Threads API de Claude para bajar hasta 70% el costo de tus automatizaciones

📝 Problema que resuelve:
Cada vez que tu automatización llama a Claude en medio de una conversación larga, envía el historial completo desde cero. Eso multiplica los tokens y el costo innecesariamente.

🎯 Resultado después:
Tendrás una automatización que reutiliza el contexto guardado en Claude, reduce tokens enviados y mantiene el mismo nivel de respuesta. Aplica para cualquier workflow conversacional.

⏱️ Tiempo: 25 minutos

PASO 1: Verifica que usas un modelo compatible con Message Threads
→ Los modelos compatibles son: claude-fable-5-1, claude-opus-4-6, claude-sonnet-4-6, claude-opus-4-5, claude-sonnet-4-5
→ Si usas un modelo antiguo, actualiza el ID en tu código o plataforma de automatización
→ Resultado esperado: Tienes el ID exacto del modelo que vas a usar anotado

PASO 2: Haz tu primera llamada con thread y guarda el thread_id
→ Agrega el header: "anthropic-beta: message-threads-2026-08-12"
→ En el body del request agrega: "thread": {"mode": "auto"}
→ La respuesta incluirá un "thread_id" que debes guardar en una variable
→ Ejemplo de primer mensaje: "Hola, soy [nombre de tu cliente]. Necesito ayuda con [tema específico]."
→ Resultado esperado: Recibes un thread_id como "thread_01abc..." en la respuesta

PASO 3: Envía el segundo mensaje referenciando el mismo thread
→ En el siguiente request, agrega: "thread": {"id": "thread_01abc..."}
→ Solo envías el mensaje nuevo, no el historial anterior
→ Prompt exacto para probar: "Con el contexto anterior, ahora quiero que me des 3 opciones concretas."
→ Claude recordará todo lo anterior aunque no lo hayas enviado de nuevo
→ Resultado esperado: Claude responde con coherencia respecto al primer mensaje, sin que lo hayas reenviado

💡 HACK EXTRA QUE ACELERA EL PROCESO:
Guarda el thread_id en Notion o Airtable asociado al ID del cliente o conversación. Así puedes retomar el contexto exacto días después sin reconstruir el historial. Claude lo recuerda por ti.

🔗 Recursos: [Message Threads Docs](https://platform.claude.com/docs/en/build-with-claude/message-threads.md) | [Claude Platform API](https://platform.claude.com/docs/en/api)
