🧠 TUTORIAL CLAUDE/IA DEL DÍA - PASO A PASO

TÍTULO: Cómo usar el sistema de effort routing de Fable 5.1 para reducir costos sin perder calidad

📝 Problema que resuelve:
Pagas el precio máximo por cada llamada a Claude cuando la mayoría de tus tareas solo necesitan el 30% de la capacidad del modelo.

🎯 Resultado después:
Rutas tareas simples a effort "low" o "medium" y reservas "max" solo para análisis complejos. Resultado: 40-60% de ahorro en API sin tocar la calidad de salida.

⏱️ Tiempo: 20 minutos

PASO 1: Identifica tus tareas por complejidad
→ Abre una hoja de cálculo y lista todas las llamadas a Claude que haces en un día
→ Clasifica cada una: Simple (resumir, clasificar, responder FAQ), Media (escribir contenido, analizar), Compleja (razonar, planear, código largo)
→ Resultado esperado: Un mapa de tus tareas con nivel de complejidad asignado

PASO 2: Asigna effort en tu código o prompts
→ En la API, agrega el parámetro thinking con budget_tokens según nivel:
→ Prompt exacto para tareas simples: agrega al header "Use low effort. This is a classification task." Para tareas complejas: "Use maximum reasoning. This requires deep analysis."
→ Resultado esperado: Claude aplica el nivel correcto y el costo varía automáticamente

PASO 3: Mide y ajusta en 7 días
→ Corre ambas configuraciones paralelas durante una semana
→ Compara: calidad de output (manual o con eval automático), costo por tarea, tiempo de respuesta
→ Resultado esperado: Un preset personalizado de effort por tipo de tarea con ahorro cuantificado

💡 HACK EXTRA QUE ACELERA EL PROCESO:
Usa "medium" como default para todo y baja a "low" solo tareas de clasificación binaria (sí/no, positivo/negativo). Esto solo ya da 25-35% de ahorro con cero pérdida de calidad en esas tareas.

🔗 Recursos: [Claude Fable 5.1 Platform Docs](https://platform.claude.com/docs/en/models/fable-5-1/overview)
