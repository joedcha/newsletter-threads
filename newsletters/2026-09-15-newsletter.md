🧠 TUTORIAL CLAUDE DEL DÍA - PASO A PASO

TÍTULO: Cómo activar prompt caching en Claude y reducir tu factura hasta un 75%

📝 Problema que resuelve:
Pagas de más en la API de Claude porque repites el mismo contexto largo (system prompt, base de conocimiento, historial) en cada llamada. Con Fable 5.1, hay una forma de cachear ese contexto y pagar solo la primera vez.

🎯 Resultado después:
Tendrás prompt caching activo en tus automatizaciones y verás una reducción real en tu consumo mensual de API, especialmente si usas agentes o chatbots con contexto persistente.

⏱️ Tiempo: 15 minutos

PASO 1: Identifica qué parte de tu prompt es estática y repetitiva
→ Abre el código o la herramienta donde llamas a la API de Claude
→ Busca tu system prompt o el bloque de contexto que envías en CADA llamada
→ Si ese bloque tiene más de 1,024 tokens (aprox. 750 palabras), es candidato ideal para cachear
→ Resultado esperado: Tienes identificado el bloque de texto que se repite siempre igual

PASO 2: Añade la marca de caché al bloque estático
→ En tu llamada a la API, modifica el bloque así:

```python
messages = [
    {
        "role": "user",
        "content": [
            {
                "type": "text",
                "text": "Tu system prompt o contexto largo aquí...",
                "cache_control": {"type": "ephemeral"}
            },
            {
                "type": "text",
                "text": "La pregunta dinámica del usuario aquí"
            }
        ]
    }
]
```

→ El bloque con `cache_control` se cachea por 5 minutos (ephemeral) o por toda la sesión
→ Resultado esperado: La primera llamada carga normal, las siguientes reutilizan el caché

PASO 3: Verifica el ahorro en tu dashboard de Anthropic
→ Ve a console.anthropic.com → Usage → filtra por los últimos 7 días
→ Busca la columna "Cache Read Tokens": si aparece con valores, el caché está activo
→ Compara "Input Tokens" vs "Cache Read Tokens": los tokens cacheados cuestan 75% menos
→ Resultado esperado: Ves que una parte significativa de tus tokens es ahora "cache read" a $0.25/M

💡 HACK EXTRA QUE ACELERA EL PROCESO:
Mueve tu base de conocimiento completa (FAQs, contexto de producto, instrucciones del negocio) al system prompt en vez de incluirla en cada mensaje de usuario. Con caching activo, ese bloque de 5,000 tokens solo se cobra completo una vez cada 5 minutos, no en cada llamada.

🔗 Recursos: [Claude Prompt Caching Docs](https://platform.claude.com/docs/en/models/fable-5-1/overview) | [Anthropic Console](https://console.anthropic.com)
