# 📰 Noticias IA — Información nueva de hoy

## 🔹 NOTICIA #1: Claude Code lanza /design — convierte ideas y pantallazos en interfaces editables desde la terminal

Anthropic lanzó esta semana en Claude Code el skill /design, que genera un canvas visual de múltiples artboards a partir de una descripción o un screenshot. El resultado es una página editable publicada directamente en el navegador: el usuario hace clic sobre cualquier elemento, lo modifica con el panel de propiedades y guarda con una sola acción. Además llegaron otras tres actualizaciones: modo Concise que responde con el resultado primero y la explicación después, auto-continue cuando se alcanza el límite de uso, y auto mode como nuevo default con reglas de permisos escritas en lenguaje natural.

**Por qué importa:**
→ Por primera vez un desarrollador puede pasar de idea a interfaz funcional y editable sin salir del flujo de código. El ciclo de diseño-implementación se comprime de días a minutos.

**Cómo aprovechar AHORA MISMO:**
→ Abre Claude Code, escribe /design con una descripción de la pantalla que más necesitas mockupear y publica el artboard en 10 minutos. Ese artefacto lo puedes compartir con tu cliente o equipo para validar antes de escribir una línea de código.

## 🔹 NOTICIA #3: OpenAI lanza Jalapeño — su primer chip de inferencia propio y el inicio del fin de la dependencia de NVIDIA

OpenAI presentó Jalapeño, su primer chip de inferencia custom. La propuesta: respuestas más rápidas, mayor throughput y mejor eficiencia energética que los GPU de terceros. El chip entra en fase de planificación de despliegue como parte de un roadmap multigeneracional de silicio propio.

**Por qué importa:**
→ El costo de los tokens de IA está directamente atado al hardware de inferencia. Si OpenAI controla su propio chip, puede reducir precios de API de forma independiente a lo que haga NVIDIA. Eso presiona a toda la industria y los precios de API para usuarios finales van a seguir bajando.

**Cómo aprovechar AHORA MISMO:**
→ Si pagas por tokens de API de OpenAI, monitorea los cambios de precio durante los próximos 60-90 días. Con Jalapeño en despliegue, es probable un corte de precios antes de fin de año. Ese momento es ideal para migrar proyectos que hoy son caros a producción real.

# 🧠 Tutorial Claude/IA del día — paso a paso

**TÍTULO: Cómo usar Claude Code /design para crear un mockup de landing page en 10 minutos**

📝 Problema que resuelve:
Necesitas validar visualmente una idea de producto o servicio antes de invertir tiempo en desarrollo, pero no tienes a un diseñador ni conoces Figma en profundidad.

🎯 Resultado después:
Vas a tener un canvas visual interactivo con los artboards de tu landing page, listo para compartir con tu equipo o cliente con un link directo desde el navegador.

⏱️ Tiempo: 10-15 minutos

**PASO 1: Abre Claude Code y carga el skill /design**
→ Ve a claude.ai/code o abre la app de escritorio
→ En el chat, escribe: /design
→ El sistema carga el skill de diseño automáticamente
→ Resultado esperado: Claude te confirma que el skill está activo y te pide describir lo que quieres diseñar

**PASO 2: Describe tu landing con el prompt exacto**
→ Instrucción: Escribe este prompt palabra por palabra (reemplaza los corchetes con tus datos):
→ Prompt exacto: "Crea el diseño de una landing page para [nombre de tu producto/servicio]. La propuesta de valor principal es [qué resuelve en una frase]. El cliente ideal es [describe a tu cliente en 10 palabras]. Incluye: hero section con headline y CTA, sección de 3 beneficios clave, sección de testimonios y CTA final. Estilo visual: moderno, minimalista, colores [tu paleta o 'defíni tú']. Genera un canvas con artboards separados para versión desktop y mobile."
→ Resultado esperado: Claude genera el canvas con los artboards y te entrega un link para ver la página en el navegador

**PASO 3: Edita los elementos directamente en el canvas**
→ Abre el link en el navegador
→ Haz clic sobre cualquier texto para editarlo directamente
→ Usa el panel de propiedades (derecha) para cambiar colores, tipografía y tamaños
→ Cuando estés satisfecho, presiona Guardar y comparte el link con tu cliente o equipo
→ Resultado esperado: Tienes un mockup visual navegable, sin haber tocado Figma ni escrito CSS

💡 HACK EXTRA que acelera el proceso:
Si ya tienes un screenshot de una landing que te gusta, adjúntala al prompt en Claude Code antes de ejecutar /design. Claude analiza la estructura visual y la replica adaptada a tu contenido. Ahorras el 50% del tiempo de iteración.

🔗 Recursos: https://www.gradually.ai/en/changelogs/claude-code/
